### B. xmc Go 对齐包（security，P2；R2 发现 → R3 双盲 6/6 证实）

1. 密码比较非恒时（conn.rs:253 `!=` vs Go server.go:219 ConstantTimeCompare）——**定谳：技术成立（CWE-208）但远程可利用性≈0**（SNR≈10⁻⁴，10⁷ 年/字节位；且 RSA 公钥由 password 确定性派生+明文下发 → 离线字典碰撞严格占优，时序预言机冗余）。修复 ~2 行（subtle 2.6.1 已在 lockfile）
2. 握手无 deadline（spawn 在 xmc/mod.rs:51,58 裸奔；Go 2min）——慢速探测资源驻留无上界
3. 无 login-profile 白名单（conn.rs:211-213 username 读入即弃；Go findProfile 双因子）
4. nextState==1 不回伪装 statusResponse（conn.rs:198-204；Go server.go:83-118）——**单次主动探测即可指纹**，削弱 finalmask 抗探测目的；附带 Login Acknowledged 未实现（conn.rs:324 自认）、tcp_bridge 全失败路径静默吞错（conn.rs:304/316/321/331）

### C. 数据路径 panic 语义（correctness，P2）

`xray-proxy-tun/src/netstack.rs:781` 家族不匹配 panic：**可构造已实证**（verify/qn002_repro 5/5 通过 + 8 环静态链），v4 TUN↔v6 上游拓扑下 task 级 panic（单 UDP 会话静默死 + 60s 僵尸队列）；Go 同位逻辑畸形包降级不 crash。修复：改 Option/Result 丢包+warn。

### D. Debug 埋雷（security，P3；R3 已证 2 类）

`RealityConfig`（含 private_key）/`UConnState`/`RealityInboundConfig`（inbound.rs:2061，含 server_private_key——R1 漏登记）/`xmc::Config`（含 password+rsa_private_key）四类型 derive(Debug)。**活跃泄露路径=0**（reality crate 全量 grep 零命中+panic hook 不 dump），属埋雷非活雷；手动 redacted 化收尾。
