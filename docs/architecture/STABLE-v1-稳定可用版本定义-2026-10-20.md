# 稳定可用版本 STABLE-v1 · 定义与验收门

> **日期**：2026-10-20
> **用户拍板**：「我想先开发一个稳定可用的版本..然后后期这些问题就在这个跟 xray-frame 一起来搞」
> **唯一 gate 票**：`Xray-core-rust-ft58`（P0 核心内核稳定性/性能优先修复）
> **延后范围**：epic `Xray-core-rust-4jmz` 下其余 16 票 → 框架期统一排期
> **本文件性质**：范围定义与验收标准，不含代码实施

---

## 0. 范围切分（一刀切）

| 轨道 | 内容 | 时机 |
|---|---|---|
| **STABLE-v1** | 9 条(S1-S9) + 2 静默丢配置 + v2 新增 4 族(A0b-1..4) **+ handoff 2 票(B0/A9)** | **现在** |
| **框架期** | 其余全部：协议级新能力 12 条、masque、Lua、抽象形态类、功能可用性/技术债长尾 | 与 xray-frame P2/P3 同批 |

**判据**（不是"功能全不全"，是**运行时行为**）：
- 静默失败（用户以为生效其实没生效）
- 互通失败（Go↔Rust 不通）
- 安全泄漏（DNS/IP 泄漏）
- 数据面性能（连接复用 / 握手开销 / 背压）
- 静默回归（有实现但无 e2e → 回归不报警）

## 1. STABLE-v1 缺口清单（11 项）


### 批次 A0 · wire 契约 · 最高优先（proto 硬冲突，票 `Xray-core-rust-o7ns`）

> 报告 `reports/parity/assets-proto.md`；基线 Go **v26.10.17** / HEAD `92ccc939`
> 协议数据面 wire **完全兼容**；**配置面 / pb / gRPC API 面不兼容**

| # | 冲突 | Go | Rust | 后果 |
|---|---|---|---|---|
| **A0-1** | `transport/internet/config.proto` QuicParams tag 6-16 全段右移 | tag6-16 全 varint | tag6 插入 `udp_hop`(message) → 顶到 7-17 | **Go→Rust tag6 解码报错；tag7-16 静默错值一格**（Go `max_incoming_streams=15` 被 Rust 当 `disable_chrome_*`）|
| **A0-2** | `proxy/wireguard/config.proto:24` DeviceConfig tag5 | `repeated protocol.User` | `int32 num_workers` | 双向解码均报错；**Go 的 WG 多用户 inbound 在 Rust 无法表达** |
| **A0-3** | `proxy/wireguard/config.proto:15` PeerConfig.keep_alive tag4 | `string`（十进制字符串） | `uint32` | 双向解码报错 |
| **A0-4** | `finalmask/xdns/config.proto` resolvers 元素类型 | `ResolverProto{type,addr,worker,tls_config,quic_config}` | `repeated TypedMessage` | 解码不报错但**语义全丢**（静默） |

**为何 32/32 + interop 54 组合全绿仍坏** → 现有互通只覆盖**数据面**，未覆盖 pb 配置 / gRPC API 路径。

**前提被推翻**：`crates/xray-proto/build.rs:36` 实测**就是从 `protos/` 编译** prost 类型，全仓零手写 derive → `protos/` **本身即 wire 契约载体**（`protos/README.md` 的「纯参考不参与编译」已过时，须同步修正）。

**附带**：`protos/` 与 Go 基线**无同步机制、无 CI 校验** → 17 处差异即漂移产物，会继续扩大（须补 Go `test.yml:38` 同款 check-proto 门）。

## 3. 开工顺序

```
B1 (Windows CI)  ← 必须先行：A2 无它无法验证
  ↓
A2/A3/A4 (TUN 三件：WFP / 路由表 / DNS+dns_skip)   [传输+协议层，框架不碰]
A1 (SOCKS UDP 早失败保护)                          [协议层]
A5 (xmc 协议层)                                    [传输层]
A6/A7 (policy + WG 数据面 e2e)                     [测试]
B2/B3/B4 (CI 门 + 嗅探 e2e + 关键 e2e)              [测试/CI]
C1 (HTTP keep-alive 最小改动 + 注释标注继承)        [装配层，与框架潜在双改]
A8 (dns 出站 Go 键名)                              [解析层]
  ↓
G2/G3/G4/G5/G6/G7/G8 全绿 → STABLE-v1
```

**并行度**：项目上限 3 并行。建议 3 轨并行：
- 轨 1（协议/传输）：A1-A5
- 轨 2（CI/测试）：B1-B4 + A6/A7
- 轨 3（装配层/解析层）：C1 + A8
