## 0. 调查方法

1. **项目规范维度**：通读 `Cargo.toml`、`rustfmt.toml`、`clippy.toml`、`deny.toml`、`ci.yml`、`release.yml`，对照 `crates/*/Cargo.toml` × 50、`crates/*/clippy.toml` × 3（仅 3 个 crate 落地 per-crate clippy）。
2. **API 设计维度**：扫描 50 个 `lib.rs` 公共导出、`Result<T, E>` 类型别名（~20 crate）、错误 facade 模式（at_warning/at_error vs xray_common::log）、FeatureFactory 注册表、lib.rs 行数分布（最小 11/最大 574）。
3. **代码规范维度**：`#[allow(...)] // 存量清零批次` grep（13+ crate / 64+ 处）、`unsafe` 块分布（5 处跨 5 crate）、`thiserror`/`anyhow` 用法、`unwrap()/expect()` 在测试代码密度。
4. **去重核对**：性能维度已立项项（alloc/MB、池化、trait 装箱）不重复；本报告专注项目治理与 API 设计层面。
